# SME 校友咨询（Alumni Advising）预约系统 · 产品功能文档

> 适用产品：香港中文大学（深圳）·经济管理学院「校友1v1咨询」预约平台
> 访问入口：`https://sme-activity-apply.cuhk.edu.cn:8000/f/aa`
> 文档受众：产品经理 / 业务方 / 测试 / 运营

---

## 一、产品概述

### 1.1 产品定位

为经管学院「校友咨询项目（SME Alumni Advising Program）」提供线上化的一对一咨询预约能力，覆盖**咨询主题发布 → 时段排期 → 学生报名 → 邮件提醒 → 取消与反馈 → 数据汇总导出**的全流程闭环。

### 1.2 目标用户

| 角色 | 身份 | 主要诉求 |
| --- | --- | --- |
| **学生** | CUHK-SZ 在校生（统一身份认证登录） | 浏览可预约的校友咨询时段，自助报名 / 取消，及时收到提醒邮件 |
| **管理员** | 经管学院职业发展中心（CDC）运营人员 | 维护咨询主题与名额，排期发布活动，导入批量排期，导出报名明细，跨活动查询统计 |
| **校友顾问**（被动参与） | 受邀返校的校友 | 收到学生预约 / 取消通知，活动前一日收到提醒 |

### 1.3 核心价值

- 学生侧：把"找校友咨询"从邮件 / 微信沟通升级为自助式在线预约，降低协调成本
- 管理侧：将人工登记表升级为结构化数据，支持批量排期与一键导出，提升运营效率
- 顾问侧：通过邮件自动触达，让顾问无需登录即可掌握预约动态

## 三、核心业务流程

```text
┌─────────────────────────────────────────┐
│            管理员后台运维                │
│  1. 维护咨询主题（含名额、顾问、内容）    │
│  2. 排期：单条创建 或 批量上传 Excel      │
│  3. 设置活动时间 / 报名起止时间           │
└───────────────────┬─────────────────────┘
                    ▼
┌─────────────────────────────────────────┐
│              学生端报名                  │
│  1. SSO 登录 → 自动建档                   │
│  2. 日历 / 列表浏览可报活动               │
│  3. 选择咨询话题 → 提交报名               │
│  4. 系统校验「同一自然周仅可预约一次」    │
│  5. 报名成功 → 学生 + 顾问 收到通知邮件   │
└───────────────────┬─────────────────────┘
                    ▼
┌─────────────────────────────────────────┐
│            触达与提醒                    │
│  · 活动前一日 21:00 → 学生 + 顾问 提醒   │
│  · 活动结束满 2 小时 → 学生 反馈问卷     │

                    ▼
┌─────────────────────────────────────────┐
│            取消与变更                    │
│  · 学生可在活动结束前 4 小时内自助取消   │
│  · 取消后 → 学生 + 顾问 收到取消邮件     │
│  · 管理员可删除活动（级联清理报名）      │
└───────────────────┬─────────────────────┘
                    ▼
┌─────────────────────────────────────────┐
│            数据汇总与导出                │
│  · 单活动明细查看                        │
│  · 按活动名 + 时间区间导出 Excel         │
│  · 跨活动报名数据查询与下载              │
└─────────────────────────────────────────┘
```

## 四、功能模块详述

### 模块 A：登录与认证

| 功能点 | 说明 |
| --- | --- |
| **管理员登录** | 用户名 + 密码登录，按角色跳转（admin → 后台，user → 学生端） |
| **学生 SSO 登录** | 跳转 CUHK 统一身份认证，首次登录自动建档，无需注册 |
| **登出** | 管理员清空本地存储返回登录页；学生额外调用 ADFS 登出 |

---

### 模块 B：学生端 — 活动浏览

| 功能点 | 说明 |
| --- | --- |
| **活动首页** | 顶部品牌条；支持按时间区间 + 活动名筛选；右上角「My Records」入口 |
| **列表视图** | 分页展示未来活动，含日期、时段、状态标签、已报/名额、Apply 按钮 |
| **日历视图** | FullCalendar 周/月/日切换，按状态着色，点击跳转报名页 |
| **状态判定** | Open（可报且距开始≥1天）/ Full（已满）/ Closed（距开始<1天或已结束） |

---

### 模块 C：学生端 — 活动报名

| 功能点 | 说明 |
| --- | --- |
| **活动详情** | 展示活动名称、富文本内容、日期与状态 |
| **话题选择** | 结构化话题清单单选，已占用选项置灰 |
| **提交报名** | 校验同周唯一规则，生成订单号（R+8位数字），自动归档学生信息 |
| **报名通知** | 成功后给学生和顾问各发一封通知邮件 |

---

### 模块 D：学生端 — 报名记录管理

| 功能点 | 说明 |
| --- | --- |
| **我的报名** | 分页展示历史报名（订单号、时间、活动名、状态） |
| **取消报名** | 活动结束前 4 小时内禁取消；二次确认后删除记录并发送取消邮件给双方 |

---

### 模块 E：管理后台 — 项目管理（咨询主题）

| 功能点 | 说明 |
| --- | --- |
| **项目列表** | 分页展示，支持按更新时间筛选，含 Edit / Delete 操作 |
| **新增 / 编辑** | 弹窗表单：名称、富文本内容、名额、所属顾问（下拉） |
| **删除项目** | 二次确认，级联删除其下所有活动与报名（⚠️ 无回收站） |

---

### 模块 F：管理后台 — 活动管理

| 功能点 | 说明 |
| --- | --- |
| **活动列表** | 分页展示，含名额、已报人数、活动/报名时间、报名链接、明细入口 |
| **新增 / 编辑** | 弹窗表单：关联项目、活动起止时间、报名起止时间（校验开始≤结束） |
| **批量上传** | 下载 14 天模板 → 填写 → 上传 .xlsx，命中已有则更新，否则新增 |
| **报名明细** | 新窗打开，顶部四宫格摘要 + 分页报名表格 |
| **删除活动** | 二次确认，级联删除该活动下所有报名 |

---

### 模块 G：管理后台 — 数据导出

| 功能点 | 说明 |
| --- | --- |
| **报表导出** | 按时间筛选 + 勾选活动名（支持全选），点击 Export 下载 Excel |
| **联动查询** | 勾选活动后底部表格实时刷新对应报名明细 |
| **Excel 字段** | 序号、活动名、订单号、姓名、学号、邮箱、时间、信息 |

---

### 模块 H：定时邮件自动化

> 由服务器 cron 调度，无需用户触发。

| 任务 | 周期 | 触发条件 | 收件人 |
| --- | --- | --- | --- |
| **顾问提醒** | 每天 21:00 | 活动开始日 = 明日 | 顾问（CC careersme） |
| **学生提醒** | 每天 21:00 | 活动开始日 = 明日 | 学生（CC careersme） |
| **反馈问卷** | 每 2 小时 | 活动结束 ≥ 2 小时且未发过 | 学生 |

- 问卷邮件去重：同一报名仅发一次
- 所有邮件由 `careersme@cuhk.edu.cn` 统一发出

## 五、业务规则汇总

### 5.1 时间规则

| 规则 | 取值 |
| --- | --- |
| 同周预约限制 | 同一 ISO 自然周仅可预约 1 次 |
| 报名截止时间 | 活动开始前 24 小时（批量上传默认） |
| 学生自助取消截止 | 活动结束前 4 小时内禁取消 |
| 状态切换（Open→Closed） | 距活动开始 < 1 天 |
| 活动列表可见性 | 仅展示未来活动（开始时间 ≥ 当日） |

### 5.2 状态机

```text
活动状态（学生侧展示）
   ┌────────┐  距开始≥1天 且 未满   ┌────────┐
   │ Closed │ ◀────────────────── │  Open  │
   └────────┘                     └────────┘
                                        │ 报名人数 ≥ 名额
                                        ▼
                                   ┌────────┐
                                   │  Full  │
                                   └────────┘
```

### 5.3 唯一性 / 级联规则

| 对象 | 唯一约束 | 删除级联 |
| --- | --- | --- |
| 项目 | name 唯一 | 删除项目 → 删除其下活动与报名 |
| 活动 | name + project_id + 时段 | 删除活动 → 删除其下报名 |
| 用户 | username + name + email | — |

### 5.4 信息字段约定

报名表有 info_1 ~ info_8 共 8 个扩展字段，当前仅 info_1 用于保存咨询话题，其余预留。

## 六、交互与体验细节

| 维度 | 说明 |
| --- | --- |
| **配色** | 品牌紫 `#763890`（顶栏 / 品牌条 / 高亮按钮） |
| **语言** | 英文为主，少量中文提示；建议后续支持中英双语 |
| **会话** | 登录态写入 localStorage，刷新不掉线 |
| **校外访问** | 登录页提示需连接 VPN |
| **二次确认** | 删除项目 / 活动、取消报名、登出 均有 Dialog 确认 |
| **文件上传** | 仅接受 `.xlsx`，上传后展示成功/失败计数 |

## 七、异常与边界处理

| 场景 | 系统行为 |
| --- | --- |
| 未登录访问管理接口 | 返回 401 |
| 同周重复报名 | 返回 403 + 提示历史预约信息 |
| 活动 / 用户不存在 | 返回 404 |
| 取消不存在的报名 | 返回 404 |
| 邮件发送失败 | 记录日志，不影响主流程 |
| 文件格式错误 | 返回 400 |
| 服务器错误 | 统一返回 500 |
| 前端接口异常 | Message 弹窗提示 |
| SSO 未绑定密钥 | 重定向回 SSO 登录页 |

## 八、待优化与建议

| # | 现状 | 建议 |
| --- | --- | --- |
| 1 | 取消按钮置灰条件与文案语义不完全一致 | 明确取消截止规则并对齐文案 |
| 2 | info_2~8 预留未启用 | 启用扩展字段收集更多信息（年级、专业等） |
| 3 | 删除为硬删除且级联，无回收站 | 增加软删除或备份再删除 |
| 4 | 查询页部分筛选条件被注释 | 恢复"按活动名多选 + 搜索 + 导出"能力 |
| 5 | 邮件模板无后台编辑入口 | 提供模板管理页 |
| 6 | 上传模板固定 14 天 28 时段 | 支持自定义日期范围 / 时段 |
| 7 | 报名成功仅 Dialog 提示 | 增加结果页 / 日历邀请（.ics）下载 |
| 8 | 顾问侧无独立查看入口 | 提供只读视图或邮件汇总链接 |
| 9 | 字段拼写不一致（如 `aictivity_name`） | 统一命名 |
| 10 | 无容量预警 | 满员 / 即将截止时通知管理员 |

### 体验增强建议

- 学生端增加日历邀请（.ics）下载
- 移动端适配（卡片式替代表格）
- 多语言支持（中英双语）
- 管理员数据看板（报名趋势、满员率等可视化）
